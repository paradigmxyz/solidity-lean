# slice-final: UniswapV2ERC20.transfer, certified at the caller 0x2000 (base #166)

**Proved: one `Shapes.Certified` statement for `UniswapV2ERC20.transfer` on the exact 1183-byte
runtime, for calls from 0x2000, composed from the merged E3/E4/E5/E8/E7 theorems through
`Slice.certified_of`.** The scoped hash premise is part of the valid calls and printed below. The two
required self-transfer cases are proved on the bytes and executed. Axioms: propext, Classical.choice,
Quot.sound only; no sorry.

Base: solidity-lean `alpharush/certified-translation` d0ab5d6 (#166), plus one commit, 2cd7aa3
(`solidity-lean.bundle` / `0001-*.patch`). It adds `Contracts/UniswapV2/ERC20/Certified/Transfer.lean`
and the lake library `ContractsUniswapV2ERC20Certified`. The stages were generated by solar at the
pinned `scripts/verify/uniswap_v2_stages-solar-rev` 6edf8f4, which is an ancestor of #2637's head
697fc68. Compiling the port at 697fc68 gives the same runtime bytes (checked: both 1183 bytes, equal).

## The statement (Contracts/UniswapV2/ERC20/Certified/Transfer.lean)

```
Certified.certified : ∃ c,
  SolidCore.Verify.VC.UniswapV2ERC20.contract? = Except.ok c ∧
    SolidCore.Refinement.Shapes.Certified (SolidCore.Refinement.solidCore Slice.fuel) c Certified.code
      Slice.ValidIn Slice.Allowed Slice.TargetPost fun x => 8199112

Slice.ValidIn := fun call => Slice.Valid Slice.Gen.deployed call ∧ Slice.Scope call
Slice.Scope := fun call => ∀ σ dst v, call = Slice.transferCall σ dst v → dst < 2 ^ 160 → v < 2 ^ 256 →
  SolidCore.Spec.ScopedSep (SolidCore.Spec.transferFootprint Slice.balanceSlot Slice.caller dst)
SolidCore.Spec.ScopedSep := fun L => SolidCore.Spec.TrustedBase.KeccakSeparated fun x => x ∈ L
Slice.caller = Generic.callerWord = 0x2000   (caller_eq)
```

`code` is `CtxGas.code`, the fresh export's bytes. The full `lean` output is in print_certified.out.
**Caller:** every source-side edge (SolidCore, E3, E4 under `oracle`) fixes the caller to 0x2000,
because `SolarTV.Call` has no caller field. The statement is labelled as being about calls from 0x2000.
(`CtxGas.gas_edge` alone holds from every caller.)

## Self-transfer cases

* Lean, on the bytes (`Final.Target.runWith`, every gas from 8199112 to below 2^256; no hash premise is
  needed): `self_max_bytes`: σmax has the caller's balance 2^256-1, and `transfer(caller, 1)` gives
  `⟨true, be32 1, [transferLog caller caller 1], slotValue σmax⟩`, so the storage is unchanged.
  `self_short_bytes`: balance 5, `transfer(caller, 6)` gives
  `⟨false, errorData subMsg, [], slotValue σshort⟩`.
* Executed: `RUNTIME_HEX=rt166.hex forge test` (forge/test/TransferSlice.t.sol, EVM osaka, 2000 fuzz
  runs) on the same 1183 bytes: exit 0, 8/8 pass, including `test_selfTransferMaxBalance` and
  `test_selfTransferInsufficient` (forge166.out).
