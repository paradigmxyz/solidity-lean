# Loop-invariant reconstruction: evidence

What this directory shows: three loops' invariants, returned unedited by z3's Spacer engine, are
proved by the Lean kernel to satisfy initiation, preservation and use, with no axiom beyond
`propext`, `Classical.choice` and `Quot.sound`. Nothing here is built by `lake build`: the
default library roots are under `SolidCore`, and these files are checked on their own.

## What is and is not proved

- The Horn clauses (`chc/*.smt2`) and the Lean statements of each obligation were written by hand
  from the Solidity source of each loop. They are **not** solar-verify's emitted verification
  conditions, and nothing here proves that they match the EVM, the compiler or solar-verify's
  encoding. Treat them as a reconstruction method, not as a certificate for any contract.
- The `*_u256` variants model Solidity 0.8 checked arithmetic as path guards: every arithmetic
  result lies in `[0, 2^256)`, and a path that would overflow reverts and is dropped. They do not
  prove that the loops never revert. The `*_int` variants use unbounded integers with the
  `uint` inputs nonnegative; they say nothing about EVM words.
- Only the invariant is searched for by an untrusted solver; the proofs check it.

Loops: `counter` (`for (i = 0; i < n; i++) count++` under `require(count + n <= limit)`, ensures
`count == old(count) + n && count <= limit`), `okwhile` (`i = 0; while (i < n) i++`, ensures
`i == n`), `drain` (`a = n; b = 0; while (a > 0) { a--; b++; }`, ensures `b == n`).

## Files

- `Reconstruct.lean`: Lean core only. Each `Inv_*` is generated by `smt2lean_inv.py` from the
  Spacer model in `chc/*.spacer.out` (a 1:1 operator translation, `let` kept, no simplification),
  and each obligation is closed by `simp only [Inv_*]; omega`. Generated by `gen_reconstruct.sh`.
  Check with `lean Reconstruct.lean` on `leanprover/lean4:v4.35.0`: 18 theorems, 0.45 s, 480 MB
  peak; output in `reconstruct-4.35.axioms.txt`.
- `SpacerPath.lean`: the same three loops through the `spacer` tactic of
  [LeanHorn/Flex](https://github.com/LeanHorn/Flex) at `79bdae0d3d7069e5239174d52e1fc26fa035d249`
  (it calls Spacer, imports the model, and certifies with `grind`). It needs Flex, so it does
  not build here; output in `spacerpath-4.35.out` (6 theorems, 3.5 s, 1.95 GB). Flex builds on
  4.35.0 with the lakefile change in `flex-4.35-bump.diff` and no source change. Flex's
  `flex_auto` (a trusted SMT axiom) was not used, and its own certificate check does not reject
  `native_decide`, so every theorem was gated by `#print axioms`. Flex's `fix` path fails on
  `counter` (recursion depth, then a heartbeat timeout), so it is not used.
- `chc/`: the Horn problems in SMT-LIB and Spacer's answers (z3 5.4.1).

Checksums are in `SHA256SUMS`.
